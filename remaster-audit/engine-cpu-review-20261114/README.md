## Strict whole-pack source-class audit

Claude's strict v2 audit decoded all **1,699 world-v3 PNGs** sequentially at below-normal priority. It requires exact valid-word bytes all1, or explicit known_words=total_words=width_words*height; malformed present validity, invalid shape/depth, wrong palette size or CRC identity rejects the source. The full alpha histogram contains only categorical 0/127/255 in every PNG. This proves categorical values, not correct spatial classes. Native references were available for 1,481 keys: **1,182 pass and 299 mismatch**, with **142,550 mismatching texel centres out of 48,162,560** checked. **218 remain NOT CHECKED** because this search found no qualifying native dump. Missing references are not passes or proof that no source exists elsewhere. [Full strict result](class-audit/class-audit-v2-world-integrated-crisp-v3.json).

All 299 mismatch keys were inherited unchanged from the parent pack. Of those, 235 include transparent/nontransparent disagreement and 64 only differ between classes127/255. Root independently passed 13 bounded source-validation/decode controls, verified 2,954 native source-file hashes and 1,481 complete-word proofs, checked result arithmetic and checked reported PNG pins against the frozen ledger. [Independent controls](strict-auditor-controls.json), [receipt verification](strict-audit-independent-receipt.json). Root did not repeat the full 1,699-image decode or visually accept the pack.

The initial checker had missing/malformed-validity and whole-image histogram gaps; its source/results are preserved, and the stricter checker returns the same per-key result. Claude traced existing prepared alternatives for all 299 keys (85 rechecked fixes plus 214 import-plan rows); 214 have not been independently revalidated here. Some old class-fix recipes only stamp individual native-centre pixels, retaining pinholes/dots and other visual defects. **Do not promote centre-only fixes as complete masks, whole-image semantic repairs or final artwork.** Native alpha code is class, not opacity. Re-encoding categorical values alone does not fix spatial ownership.

The separate world-v4 preparation changes one K-panel file and passes native admission, but this whole-pack audit was on frozen world-v3. Its prior counts must not be relabeled as a new v4 full-pack run. K correction does not clear the other inherited defects. Broader repairs must keep full art provenance, source-validity and mask/shape checks, preserve the approved five-sign candidates and compare actual output in motion after GPU authorization. The full remaster, audio acceptance, ray tracing, DLSS, realistic skin library, HUD/menus and seven-stage release remain unfinished.
