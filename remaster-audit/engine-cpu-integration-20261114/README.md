## Mesh resource staging

The separate CPU adapter constructs the official SDK 0.6.11 MeshInfo/HardcodedVertex layout from three address/word-validated, same-frame committed PGXP DATAFLOW vertices. It verifies live transform records and recomputed raw accumulators, rejects diverged/mixed/stale inputs, owns its arrays and clears output on failure. Geometry stays in original model coordinates; the combined camera/object transform is retained separately. The resource hash includes geometry, UV/color and material identity, excluding frame, transform and pointers. Flat geometric normals are a staging default, not authored ship normals. UVs and SDK-format colors must already be resolved by the caller.

The [host run](scene-packet/host-results.json) passed **48 checks, zero failures**, compiling against a pinned official SDK header. Fixtures use a deliberate dummy material handle, not a live game resource. Tests cover rejection paths, pointer ownership and resource identity across view changes. Compiler warnings in inherited headers remain in the log. Sampled RSS is for the direct spawned PID only; it does not measure the compiler process tree. This prototype is **not linked into v60, connected to its frame hook, or submitted to Remix**. Independent Claude review was requested and remains pending at this publication checkpoint. No SDK call, renderer Startup, camera reconstruction, instance transform, texture/material allocation or external presentation is implemented here.
