Diagnostic Artifacts the Runtime Writes

File (in build-release\)Meaning
psx_freeze_heartbeat.jsonWritten while running: per-tick frame/cycle counters, current function, CPU registers, RAM peeks. If the game wedges, the last heartbeat shows the loop it's stuck in (e.g. cur_fn 0x29CC polling inside 0x80013xxx).
psx_freeze_dump_psx-runtime_*.jsonFull CPU-state dumps on freeze events. Safe to delete after triage.
psx_last_run_report.jsonPer-run summary; regenerated each launch.
overlay_captures.json(.d)Additive overlay capture store — keep this one.

All psx_freeze_* / psx_last_run_report.json files are regenerable — deleting them is safe cleanup.

Reading the Startup Log

Launch with stderr redirected:

cd build-release
.\Einhander_Recompiled.exe --no-launcher 2> err.log

Key lines and what they prove:

LineProves
renderer = opengl (opengl)GL backend selected
supersampling Nxsettings value actually applied — not just present in the file
GL GPU pipeline ready (internal scale Nx)FBO scale engaged — the definitive scale check
sync-to-host-refresh: pacing to 60.0 Hzframe pacing armed

Symptoms → Causes (Seen So Far)

SymptomActual cause
"8× looks identical to native"Settings parser dropped supersampling>4 → ran 1×. Fixed in config_loader.cpp.
Severe lag / machine crawl at 8×64× fill cost — exceeds this GPU. Use ≤4×.
"Can't close the test window"Fullscreen test instances. Rule: test runs use fullscreen = 0.
Leftover lag after a testOrphaned instance still running — kill via Stop-Process -Name Einhander_Recompiled.
Build fails LNK1181: m.libWrong toolchain (MSVC). Use the clang pack — see Handoff §7.

Pitfalls to Not Repeat

  • Never claim scale from settings.toml alone — check the internal scale Nx log line.
  • Never claim visual improvement without a frame capture (present_shot).
  • Never fullscreen a test instance — they are hard to close.
  • Kill all Einhander processes after tests — orphans keep burning GPU.
  • Don't assume the stderr redirect flushes everything — some runs only flushed the first lines; the heartbeat file showed the game was actually running.
  • Batch helpers with LF endings break under cmd — PowerShell env vars are the reliable path for the clang build.

Kill Command (copy-paste)

Get-Process | Where-Object { $_.Name -match "Einhander" } | Stop-Process -Force
