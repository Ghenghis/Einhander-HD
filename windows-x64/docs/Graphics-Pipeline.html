The Root Cause That Blocked Everything

BUG — FIXED psxrecomp\recompiler\src\config_loader.cpp

The user-settings parser silently rejected supersampling > 4:

// line ~2251 (was):
if (n >= 1 && n <= 4) { s.supersampling = (int)n; s.has_supersampling = true; }
// now:
if (n >= 1 && n <= 8) { s.supersampling = (int)n; s.has_supersampling = true; }

With supersampling = 8 in settings.toml, has_supersampling stayed false → g_video_scale stayed 1 → log showed internal scale 1x. Every 8× test ran at native resolution. The game-config parser had a matching 1..4 throw-range, also raised to 1..8.
