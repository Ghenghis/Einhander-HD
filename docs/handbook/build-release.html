Prerequisites and generation

Read windows-x64/psxrecomp/docs/BUILDING.md, windows-x64/psxrecomp/docs/GAME_PROJECT_SETUP.md and windows-x64/psxrecomp/docs/LOCAL_CODEGEN_SDK.md. Framework and UI trees are inline copies; a recursive clone does not reconstruct their historical pins. Preserve licenses.

python windows-x64/psxrecomp/psxrecomp_cli.py generate --help

From windows-x64, after supplying local game.toml, disc and toolchain:

python psxrecomp/psxrecomp_cli.py generate --config game.toml --project-root . --disc "disc/Einhander (USA).cue"
cmake -S . -B build-release -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build-release --target psx-runtime

The game CMake file references a local assets/psxrecomp.ico. Supply it or make an intentional local configuration change. Generated game/BIOS C and machine configuration are excluded from public history. The commands above describe the configured workflow; they are not a report that clean-checkout generation passed.

Private experiment build

remaster-audit/build_stage1_sampling_probe.py rebuilds selected real runtime units and links pinned local objects. It validates the pinned inputs and writes an immutable build.json. Compilation is CPU-only; --test includes hidden real-GL checks and needs the shared GPU slot.

python remaster-audit/build_stage1_sampling_probe.py --output remaster-audit/dev-center-evidence/stage1-completion-20261112/FRESH-BUILD-NAME
python remaster-audit/build_stage1_sampling_probe.py --output remaster-audit/dev-center-evidence/stage1-completion-20261112/FRESH-BUILD-NAME --test

Replace FRESH-BUILD-NAME once. Never rebuild over an accepted immutable directory or edit a frozen parent through hardlinks. A pinned-object build is a local experiment, not a portable release procedure.
