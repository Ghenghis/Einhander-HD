Artwork and pack import

Use native source identity and draw evidence to bind artwork. A visually plausible PNG or a matching filename alone does not establish a correct replacement.

Pack and source format

The canonical replacement directory is einhander-texture-replacements. Keys are uppercase WORDS_CRC-CLUT_CRC pairs, formatted XXXXXXXX-XXXXXXXX.png. Source pixels are 16-bit little-endian VRAM words; paletted modes also require the exact CLUT. Depth 0/1/2 denotes 4/8/16 bpp. Native width is source-word width × 4/2/1 respectively.

CRC identifies the native word/palette pair; SHA-256 pins complete file bytes and manifests. Full-upload registration and ExactRegions additionally preserve source geometry, page location, CLUT location and used UV rectangles. Check used draw context: a page may contain unrelated signs, HUD elements or actor parts.

Alpha and compositing

Replacement alpha is categorical: 0, 127, 255, preserving transparent, semi-transparent/STP and opaque classes. Class-exact acceptance compares the native category at every native texel center. Arbitrary antialias alpha, an attractive screenshot or a matching image size is insufficient.

Partial-page revisions must retain parent pixels outside their owned region. W4 import planning found shared-page overwrites and replaced them with composites. A candidate can use hardlinks to immutable parent files, but every changed file must be replaced atomically; never write through a parent hardlink. Verify every parent hash after composition.

Composer

remaster-audit/build_stage1_frozen_candidate.py accepts a pinned parent, pinned manifests and image entries. An entry may carry native_source for a complete upload or exact source words, CLUT, shape, page coordinates, UV rectangle, depth and CLUT coordinates. Optional alpha/emissive/source handoffs are separately pinned. A fresh direct-child output directory is mandatory.

python remaster-audit/build_stage1_frozen_candidate.py --plan PATH/TO/reviewed-plan.json --output remaster-audit/dev-center-evidence/stage1-completion-20261112/FRESH-PACK

In-game acceptance

  1. Verify native words, CLUT, decode, UV and class categories.
  2. Compose into a new candidate and verify lineage/unchanged keys.
  3. Observe the actual mapped replacement draw before using footage as evidence.
  4. Review entry, front, angled and exit motion at normal game speed, with obstruction/load disclosed.
  5. Check palette phases, actor states, masks, seams and shared pages.
  6. Measure ordinary gameplay/audio separately from recorder-heavy visual footage.
  7. Install only after the final candidate and runtime pass release gates.
